# DevInsight implementation plan

The implementation follows the supplied SRS in this order:

0. Project planning and repository baseline
1. FastAPI, configuration, SQLAlchemy, and PostgreSQL foundation
2. Next.js frontend foundation
3. GitHub OAuth
4. GitHub API integration and repository models
5. Redis/Celery synchronisation
6. Analytics engine
7. Repository dashboard
8. ML dataset construction
9. PR risk model
10. ML integration and explanations
11. Anomaly detection and semantic search
12. Docker and CI/CD
13. Cloud deployment
14. Testing and benchmarking
15. Documentation hardening

Each phase should leave the application runnable and should add tests for the behaviour introduced.
